# 坦克大战 (Tank Battle)

一个用纯 HTML + Canvas + JavaScript 实现的经典《坦克大战》（Battle City）网页游戏。单文件、零依赖，双击 `index.html` 即可游玩。

## 玩法

- 控制我方坦克，消灭不断出现的敌方坦克，保护底部中央的**老鹰基地**。
- 每关共 20 个敌人（同屏最多 6 个），全部消灭后进入下一关。
- 基地被摧毁或生命耗尽则游戏结束。
- 砖墙可被击碎，钢墙只有 3 级火力才能击碎，水无法通行，树丛会遮挡坦克。
- 击杀**闪烁的敌人**会掉落道具。

### 道具

| 图标 | 效果 |
|------|------|
| ★ | 火力升级（最多 3 级：1 级加速子弹 → 2 级双发 → 3 级击碎钢墙） |
| 盾 | 临时无敌护盾 |
| +  | 增加一条命 |
| 炸 | 消灭场上所有敌人 |
| 钟 | 冻结所有敌人一段时间 |

### 敌方种类

| 颜色 | 类型 | 血量 | 得分 |
|------|------|------|------|
| 红 | 普通 | 1 | 100 |
| 橙 | 快速 | 1 | 200 |
| 绿 | 重装 | 3 | 300 |
| 灰 | 装甲 | 4 | 400 |

## 操作

| 按键 | 功能 |
|------|------|
| 方向键 / WASD | 移动 |
| 空格 / J | 射击 |
| P | 暂停 / 继续 |
| R | 重新开始 |
| 回车 | 开始 / 再来一局 |

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

也可以本地起一个静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
